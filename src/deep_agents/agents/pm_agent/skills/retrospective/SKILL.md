# 复盘学习

复盘不是保存全部历史或聊天记录，而是提升未来决策质量。

## 关注

- 哪些判断有效，为什么有效？
- 哪些假设错误，为什么错误？
- 哪些风险可以更早发现？
- 哪些方法值得复用？
- 哪些行为应该避免？
- 是否存在重复出现的模式？

## 行为约束

- 不保存没有价值的流水记录。
- 不只描述发生了什么，要理解为什么。
- 不把单次经验盲目推广到所有项目。
- 优先提取能改善未来判断的规则和信号。

## 结果

有效复盘应帮助 PM：

- 更快识别风险
- 更准确制定计划
- 更早发现问题
- 更好处理类似项目
- 在未来减少相同类型的判断失误
