# 复盘学习

复盘的目标是改善未来判断，而不是完整保存过去发生的一切。

## 关注

- 哪些判断有效，为什么有效。
- 哪些假设错误，为什么当时看起来合理。
- 哪些风险信号其实可以更早发现。
- 哪些方法或判断规则值得复用。
- 哪些行为带来了无效成本或重复失败。
- 是否出现过类似模式，它们真正共同的原因是什么。
- 这次经验在什么条件下适用，在什么情况下不应推广。

## 值得沉淀的内容

优先保留未来再次遇到类似情境时能改变决策的内容，例如：

- 一个可靠的风险信号。
- 一个容易误判的假设。
- 一个有效的验证方式。
- 一个值得优先检查的失败模式。
- 一个明确的适用或失效条件。

## 行为边界

- 不写项目流水账。
- 不保存没有未来决策价值的细节。
- 不只描述结果，要理解形成结果的原因。
- 不因单次成功或失败就创造绝对规则。
- 经验不足以泛化时，保留为带条件的观察。

好的复盘应让下一次判断更快、更准，而不是让知识库更大。
