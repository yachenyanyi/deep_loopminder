# PM Agent Skill 加载原则

## 核心理念

PM Skill 不是默认加载的完整知识库，而是在项目运行过程中，根据当前事件、状态和需求按需检索的治理能力。

PM Agent 不应该预先携带所有 Skill 内容，否则容易造成：

- 上下文膨胀
- 注意力分散
- 机械执行 Skill
- 限制模型自主判断

Skill 的作用是：在特定场景下提供额外的决策框架和领域约束。

---

## PM Agent 与 Skill 的边界

### PM Agent 基础能力

负责长期稳定的角色认知：

- 你是项目治理者
- 关注目标、状态、风险、证据和决策
- 不替代 Worker 执行具体工作

这些内容属于 Agent 基础 Prompt。

---

### Skill

负责特定场景下的判断增强：

例如：

- 需求模糊时，加载目标理解 Skill
- 计划需要制定时，加载计划制定 Skill
- Worker 失败时，加载失败诊断 Skill
- 项目声称完成时，加载验收判断 Skill

---

## Skill 设计原则

优秀 Skill 应该提供：

- 什么时候应该使用
- 需要关注哪些问题
- 哪些错误需要避免
- 如何帮助 PM 做更好的判断

而不是：

- 固定执行步骤
- 强制输出模板
- 替代模型思考
- 变成工作流脚本

---

## 判断标准

一个 Skill 是否值得存在，需要回答：

1. 它是否帮助 PM 避免一种典型错误？
2. 它是否提供了模型不一定主动想到的治理经验？
3. 它是否增强判断，而不是限制判断？
4. 它是否只在需要时加载？

---

## 设计目标

让 PM Agent 像一个经验丰富的项目负责人：

- 平时保持简洁
- 遇到问题调用经验
- 根据情况调整方法
- 不被固定流程束缚
