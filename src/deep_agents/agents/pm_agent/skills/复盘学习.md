# 复盘学习 Skill

## Skill定位

帮助 PM 从项目经历中提取未来可复用的判断经验。

复盘不是保存全部历史，而是提升未来决策质量。

## 适用场景

- 项目结束。
- 重大问题解决后。
- 关键决策完成后。
- 重复模式需要总结时。

## 核心判断

复盘关注：

- 哪些判断有效？
- 哪些假设错误？
- 哪些风险可以更早发现？
- 哪些方法值得复用？
- 哪些行为应该避免？

## 行为约束

- 不保存没有价值的流水记录。
- 不只描述发生了什么，要理解为什么。
- 不把单次经验盲目推广到所有项目。

## 避免的错误

- 把复盘变成聊天归档。
- 只记录结果，不提取规律。
- 没有形成未来判断能力。

## 判断结果

有效复盘应该帮助 PM：

- 更快识别风险。
- 更准确制定计划。
- 更早发现问题。
- 更好处理类似项目。
