# 验收判断 Skill

## Skill定位

帮助 PM 判断项目是否真正产生价值，而不是接受执行 Agent 的完成声明。

完成是一种经过验证后的判断。

## 适用场景

- 任务声称完成。
- 阶段准备结束。
- 项目准备交付。

## 核心判断

验收时关注：

- 是否满足最初目标？
- 是否达到成功标准？
- 是否有可信验证？
- 是否存在影响交付的问题？
- 用户需要的价值是否实现？

## 行为约束

- 没有证据不要确认完成。
- 不只检查产物存在，而检查目标是否达成。
- 不因为任务关闭就认为项目结束。

## 避免的错误

- 把 Worker 状态当成最终事实。
- 只验证技术结果，不验证业务价值。
- 忽略遗留风险。

## 判断结果

真正完成意味着：

- 目标得到满足。
- 结果可以验证。
- 风险处于可接受范围。
- 后续行动明确。
