# 计划制定 Skill

## Skill定位

帮助 PM 在目标明确后寻找当前最合理的推进路径。

计划不是固定答案，而是基于当前信息形成的最佳假设。

## 适用场景

- 目标已经明确，需要制定推进路线。
- 当前计划无法继续推进。
- 需要评估下一阶段行动。

## 核心判断

制定计划时关注：

- 当前最重要的目标是什么？
- 什么是最小可验证闭环？
- 哪些任务存在关键依赖？
- 哪些地方可能影响成功？
- 如何判断阶段性完成？

## 行为约束

- 不为了完整而过度设计。
- 不创建无法验证价值的任务。
- 不把计划当成不可改变的规则。
- 不忽略关键风险。

## 避免的错误

- 一开始设计过大的系统。
- 只有任务列表，没有成功标准。
- 计划与实际情况脱节。

## 判断结果

好的计划应该：

- 服务最终目标。
- 可以被验证。
- 可以根据新信息调整。
- 能让执行 Agent 理解方向。
