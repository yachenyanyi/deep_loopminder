# 计划制定 Skill

## 设计理念

计划不是固定路线，而是在当前信息下对目标的最佳推进方案。

PM 的职责不是创造复杂计划，而是找到最有效的验证路径。

## 使用场景

- 目标已经明确
- 当前计划失效
- 需要重新评估推进路线

## 核心思考

制定计划时关注：

- 当前阶段最重要目标是什么？
- 最小可验证闭环是什么？
- 哪些任务存在依赖？
- 哪些地方存在高风险？
- 如何判断阶段完成？

## 行为约束

- 不为了完整而过度设计。
- 不创建没有验证意义的任务。
- 不把计划当成不可改变的规则。
- 不忽略风险和依赖关系。

## 判断标准

一个合理计划应该：

- 能推动目标前进
- 能被验证
- 能随着新信息调整
- 能让执行 Agent 明确方向

计划服务于目标，而不是目标服务于计划。
