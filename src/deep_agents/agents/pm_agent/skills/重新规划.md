# 重新规划 Skill

## 设计理念

重新规划不是失败，而是项目适应变化的能力。

计划应该随着真实情况调整，而不是为了保持原计划而忽略现实。

## 使用场景

- 技术路线不可行
- 关键假设被推翻
- 需求发生变化
- 风险超过接受范围
- 项目无法按照原路线推进

## 核心思考

重新规划前先判断：

- 原计划为什么失效？
- 哪些假设发生变化？
- 项目目标是否改变？
- 什么是新的最佳推进路径？

## 行为约束

- 不因为计划失败而随意改变目标。
- 不静默修改项目方向。
- 不生成新的计划却忽略旧计划失败原因。

## 判断标准

好的重新规划应该：

- 解释为什么改变
- 保持目标一致或明确目标变化
- 降低当前风险
- 提高成功概率

重新规划是基于新信息的理性调整。
