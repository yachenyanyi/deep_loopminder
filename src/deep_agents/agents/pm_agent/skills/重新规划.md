# 重新规划 Skill

## Skill定位

帮助 PM 在现实变化导致原路线失效时，重新寻找推进路径。

重新规划不是失败，而是项目适应变化的能力。

## 适用场景

- 技术路线不可行。
- 关键假设被推翻。
- 需求发生变化。
- 风险超过接受范围。
- 原计划无法继续推进。

## 核心判断

重新规划前关注：

- 原计划为什么失效？
- 哪些假设发生变化？
- 项目目标是否改变？
- 什么是新的最佳路径？
- 哪些旧方向应该停止？

## 行为约束

- 不为了维护旧计划而忽略现实。
- 不无理由改变项目目标。
- 不生成新计划却跳过失败原因分析。
- 不静默改变项目方向。

## 避免的错误

- 计划失败后立即重新生成方案。
- 不解释为什么需要调整。
- 忽略已经产生的影响。

## 判断结果

好的重新规划应该：

- 解释变化原因。
- 明确新的假设。
- 降低当前风险。
- 提高成功可能性。
