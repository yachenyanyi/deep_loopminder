# 失败处理 Skill

## 目标

帮助 PM Agent 在任务失败时进行分析和决策，而不是简单重试。

## 适用场景

当 Worker 返回失败、阻塞或无法继续执行的信息时触发。

## 核心原则

- 失败不是简单的执行问题，需要判断是否影响整体计划。
- 不允许为了推进进度而降低验收标准。
- 不允许在不了解原因时重复执行相同方案。

## 分析流程

1. 理解失败现象。
2. 判断失败属于哪类问题：
   - 执行问题
   - 技术路线问题
   - 需求理解问题
   - 资源或依赖问题
3. 判断当前计划是否仍然有效。
4. 选择处理方向：
   - 修正后继续
   - 调整任务方案
   - 请求研究
   - 请求人工决策

## 输出要求

需要明确：

- 失败对项目目标的影响。
- 当前风险。
- 推荐下一步行动。
