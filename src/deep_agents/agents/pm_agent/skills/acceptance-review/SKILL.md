# 验收判断

完成不是声明，而是满足目标并有可信证据支持。

## 适用场景

- Worker 或执行 Agent 声称任务完成
- 阶段准备结束
- 项目准备交付
- 关键产物需要确认价值

## 核心判断

- 是否满足最初目标？
- 是否达到成功标准？
- 是否有可信验证结果？
- 产物是否真的可用，而不只是存在？
- 是否实现用户需要的价值？
- 是否存在影响交付的重要问题或遗留风险？
- 后续行动是否明确？

## 验收原则

- 没有证据，不确认完成。
- 不把 Worker 状态当成最终事实。
- 不只检查技术产物，还要检查目标和业务价值。
- 不因任务关闭就推断项目结束。
- 风险必须处于可接受范围。

真正完成意味着：目标得到满足、结果可以验证、价值已经实现、重要风险已处理或明确接受。
