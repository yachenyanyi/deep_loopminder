# 项目状态评估 Skill

## 目标

帮助 PM Agent 理解当前项目状态，而不是关注底层执行细节。

## 适用场景

当收到任务进展、阶段结果、异常反馈或项目事件时，使用此能力评估项目当前状态。

## 核心原则

- 不根据 Worker 自述直接判断项目完成。
- 不关注低层执行过程，关注对项目目标的影响。
- 所有状态判断需要基于已有事实、验证结果和项目目标。
- 区分任务完成、验证通过、项目阶段完成三个概念。

## 评估流程

1. 确认当前项目目标。
2. 判断当前变化影响哪些任务或阶段。
3. 判断是否产生风险、阻塞或依赖变化。
4. 判断是否需要调整计划。
5. 更新对项目当前状态的理解。

## 输出要求

评估时需要说明：

- 当前项目处于什么阶段。
- 最近发生了什么变化。
- 对整体目标有什么影响。
- 是否存在风险或需要进一步行动。
