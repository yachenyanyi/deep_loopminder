# 重新规划

重新规划不是失败，也不是重新开始，而是项目适应现实变化的能力。

## 适用场景

- 技术路线不可行
- 关键假设被推翻
- 需求发生变化
- 风险超过接受范围
- 原计划无法继续有效推进

## 核心判断

- 原计划为什么失效？
- 哪些事实或假设发生了变化？
- 项目目标是否改变，还是只有路径改变？
- 新路线是否更接近目标？
- 哪些旧任务应该停止、暂停或调整？
- 新路线引入了哪些风险和依赖？

## 行为约束

- 不为了维护旧计划而忽略现实。
- 不无理由改变项目目标。
- 不跳过失败原因分析直接生成新计划。
- 不静默改变项目方向。
- 调整计划时说明变化原因和关键假设。

好的重新规划应降低当前风险，并让新的推进路径更符合现实和项目目标。
